# Розробка простого торгового алгоритму на Python.
## Склад команди: Колеснікова Марія та Єршова Анастасія.
### Метою проєкту було познайомитись з основними аспектами алгоритмічної торгівлі, проводячи їх через процес отримання фінансових даних та розробки базової моделі торгівлі.
### Нашим інструментом для торгівлі було обрано нафту, оскільки вона є ключовим енергетичним ресурсом та одним з найліквідніших біржових активів у світі. 

### Структура проєкту

- data.py — завантаження історичних даних;
- strategy.py — обчислення ковзних середніх та генерація торгових сигналів;
- visualization.py — побудова графіка та підрахунок результату стратегії;
- main.py — запуск проєкту.    
Використовуються дві ковзні середні:
- MA20 (20 торгових днів);
- MA50 (50 торгових днів).

Правила стратегії:
-  Купівля — коли MA20 перетинає MA50 знизу вгору.
-  Продаж — коли MA20 перетинає MA50 зверху вниз.    
Програма:
- завантажує історичні дані;
- обчислює ковзні середні;
- визначає точки купівлі та продажу;
- обчислює загальний прибуток (або збиток);
- будує графік із торговими сигналами.                  
Для дослідження ми використали історичні дані про нафту WTI  (тикер CL=F ) за два роки — з 01.01.2023 по 31.12.2024. Саме на цих даних будувались ковзні середні та перевірялась ефективність торгової стратегії.

### В процесі аналізу використовувались такі бібліотеки: yfinance для отримання даних про актив(його ціни в конкретні періоди), pandas для створення датасету та matplotlib.pyplot для візуалізації результатів.
### Для того, щоб завантажити дані, було створено відповідну функцію.

### Торгова стратегія є доволі відомою та часто використовуємо, проте в процесі аналізу та трейдингу нашим активом ми зазнали збитків, це може бути спричинено тим, що ціна нафти суттєво залежить від політичної ситуації, що часто є непередбачуваною.
